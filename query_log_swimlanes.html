Case-insensitive; . matches newlines. Capture groups become the lane label. Named group (?<color>...) colors bars by captured value. Empty = show all. Recent filters are saved and selectable from this box.
Times are UTC, matching query log timestamps. Combined with the regex using AND. Empty bounds = no time limit.
Hardcoded parsing rules
  • JSONL: timestamp from time. Start when event indicates start. End when event indicates success/failure. Correlation id is id. Lane label & grouping is query.
  • Text: a new message starts only when the line begins with a timestamp (continuation lines, including Cypher line breaks, are joined). Start when the message contains "Query started". End is the next non-start message. Correlation id extracted from id:123. Query derived as: take text after ">", split by " - ", take the 3rd element.
  • If a file has no start entries (completed-only), start is inferred as end timestamp minus elapsed time (text: - 2 ms:; JSON: elapsedTimeMs).
  • Parquet (including gzip-compressed columns and .parquet.gzip): one row is one finished query. time is the end timestamp. Duration is queryMillis or elapsedTimeMs, in milliseconds. A non-empty error marks a failure. Large files are read by page and evenly sampled (a few thousand queries) so the whole column is never loaded into memory. Zooming or panning re-reads the file for that time window, again capped at the same sample size; when the window holds fewer queries than that, every one is shown.
  • Regex and time-range filters are combined with AND. An interval is kept if it overlaps the selected window.
  • Zooming the plot keeps that time window and drops lanes that do not overlap it. Double-click the plot, or use the modebar home button, to show every lane again.
  • Bar color: default blue, failures red. With (?<color>...), each distinct captured value fully sets the bar color. Other capture groups still form the lane label. Click a label to open the full log line.
If your end-lines don’t carry timestamps, pairing will be approximate (we need a timestamp to close an interval).
